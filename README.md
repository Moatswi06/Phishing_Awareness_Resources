# Phishing_Awareness_Resources

A comprehensive cyber security resource HUB for identifying, reporting and preventing phishing attacks.

## PROJECT OVERVIEW
This repository provides educational guidelines, checklists, reporting templates2, and technical utilities designed for Junior Cybersecurity analysts and Organizational awareness training.

## Repository Structure
-**`docs/`**: contains core security documentation including phishing guides and red flag checklists.
-**`Templates/`**: standard operating templates, such as incident reporting forms.
-**`scripts/`**: automation tools, including a Python phishing indicator detector script.

## Project Files
1. `docs/Phishing attack overview & prevention.md` - technical overview of phishing types, domain spoofing, defense tactics.
2. `docs/avoid phishing& incident report.md` - quick inspection  checklist for identifying suspicious emails.
3. `templates/phishing_incident_report.md` -intake template for reporting phishing incidents.
4. `scripts/phishing_detector.py` - python utility to scan addresses, links and content for phishing red flags.

## HOW TO USE
- **Documentation**: access the `docs/` folder to review awareness materials or run employee training modules.
- **Incident Reporting**: utilize `templates/phishing_incident_report.md` to document training modules.
- **Phishing Detector**: run the python detector locally using:
```bash
python scripts/phishing_detector.py
